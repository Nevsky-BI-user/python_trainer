# Конвенції проєкту

Vite 8 + ванільний JS (ES-модулі), CodeMirror 6, Pyodide 314.0.7 у воркері. Опис і
структура: README.md. Як писати контент: CONTENT.md.

## Команди перевірки

- `npm run check`: vitest, прогін усього контенту в Pyodide під Node (`Усе зелене`), збірка.
- `python scripts/check_layout.py`: ворота розкладки за рендером, 1920 і 1440 плюс 390,
  канарки і справжній Python у браузері; код виходу 1 на будь-яку розбіжність. Вивід
  цитується у звіті.
- Дрібна правка (текст, підпис, один елемент): `python scripts/check_layout.py --only
  <сторінка> --widths 1440 --no-python`, сторінки: home, lesson, task, sandbox, notfound,
  mobile, canary, python.
- Контент: `npm run verify -- --only <id>` (урок `l7-2`, модуль `m7`, рівень `p4`, задача `p4-1`).

## Правила

- Очікуваний вивід і числа перевірок беруться з прогону еталону (`verify`), не з голови.
- Версія Pyodide в `src/runtime/version.js` і `devDependencies.pyodide` однакова: її
  тримає тест `tests/content.test.js`. Міняються разом, після цього `npm run check`.
- `harness.py` один для браузера і Node: правка поведінки перевірки йде лише туди.
- Стоси рядків мають спільні колонки: ширина за вмістом рахується на весь стос
  (`fitColumn` у `src/ui/dom.js`, `--count-ch`, `--level-count-ch`), лічильники в `ch`
  з `tabular-nums`. Число стоїть одразу за найдовшою назвою стосу.
- Новий стос чи ряд блоків: перевірка у `scripts/check_layout.py` і канарка до неї, що
  доводить спрацювання.
- Зменшений рух: переходи `0s`, а не `0.01ms`. Ненульова тривалість за типового
  `transition-property: all` робить переходом кожну зміну стилю, і синхронний замір
  бачить старе значення.
- Вміст рендериться через `h()`/`fill()` з `src/ui/dom.js`: масиви розгортаються, `null`
  і `false` пропускаються. `replaceChildren` з масивом друкує `[object …]`.
- Підказки (`hint`) звичайний текст; HTML лише в `theory`, `story`, `task`.
- Робочі копії гілок: `.claude/worktrees/<назва>`; знімки, логи, разові файли: `.local/`.
