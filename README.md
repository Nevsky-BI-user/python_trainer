# Python-тренажер для дата-аналітика

Локальний тренажер Python для аналітика даних: теорія з прикладами, вправи з миттєвою
перевіркою і практикум із багатокрокових задач на п'яти рівнях складності. Код виконується
справжнім Python у браузері (Pyodide у воркері) з pandas, numpy і matplotlib.

## Що всередині

- Уроки: 9 модулів, 31 урок, 117 прикладів, 191 вправа. Від змінних і колекцій до numpy,
  pandas, очищення, структурування і візуалізації даних.
- Практикум: 5 рівнів, 15 задач, 79 кроків. Задача веде одні дані через кілька кроків,
  на рівнях 4-5 дані брудні по-справжньому: спершу очищення, потім структура, зведення і
  графік. Перед кроком k виконуються еталонні розв'язки кроків 1..k-1, тож будь-який крок
  можна розв'язувати окремо.
- Перевірка: точний вивід і перевірки на Python (значення, типи, дані графіків),
  порівняння виводу з першим розбіжним рядком, пояснення типових помилок українською.
- Пісочниця для вільного коду, графіки matplotlib показуються картинками під кодом.
- Прогрес і код зберігаються в браузері (localStorage), є експорт і імпорт у файл.
- Світла і темна теми, розкладка від 390 px. Клавіші: Ctrl+Enter запуск,
  Ctrl+Shift+Enter перевірка, `/` пошук у змісті.
- Зациклений код зупиняється через 12 с, Python перезапускається сам.

Python вантажиться з CDN jsdelivr, тому застосунку потрібен інтернет.

## Запуск

Перевірено на Node.js 24.22.

```powershell
npm ci
```

```powershell
npm run dev
```

Vite покаже адресу, типово http://localhost:5173. Зібраний застосунок (`npm run build`,
тека `dist`) працює з будь-якої теки чи підшляху статичного хостингу.

## Перевірки

```powershell
npm run check
```

Модульні тести (vitest), прогін усього контенту справжнім Pyodide у Node і збірка. Звіт
контенту закінчується рядком «Усе зелене»: кожен еталон проходить, кожен стартовий код
не проходить, схема і текст чисті.

```powershell
python scripts/check_layout.py
```

Ворота розкладки за рендером у Chromium без голови (звук вимкнено, рух зменшено):
ширини 1920 і 1440 плюс мобільна 390, допуск 1 px. Спільні межі блоків і колонок, сталі
кнопки між станами, числа на екрані проти контенту, канарки (навмисні дефекти, які кожна
перевірка мусить зловити) і справжній Python: вправа, кроки задачі, графік, пісочниця.
Знімки сторінок лягають у `.local/layout/`. Потрібні Python 3 і Playwright:

```powershell
pip install playwright; python -m playwright install chromium
```

Для дрібної правки досить однієї сторінки на одній ширині:

```powershell
python scripts/check_layout.py --only home --widths 1440 --no-python
```

Сторінки для `--only`: home, lesson, task, sandbox, notfound, mobile, canary, python.

## Структура

```
src/content/    уроки (lessons/) і задачі практикуму (practice/); як писати: CONTENT.md
src/core/       каталог, перевірка відповіді, прогрес, схема контенту
src/runtime/    Pyodide у воркері; harness.py спільний для браузера і Node
src/ui/         інтерфейс без фреймворку: маршрути, редактор CodeMirror 6, сторінки
scripts/        verify-content.mjs (контент у Pyodide під Node), check_layout.py (ворота розкладки)
tests/          модульні тести vitest
source/         вихідний артефакт, з якого почався проєкт
```
